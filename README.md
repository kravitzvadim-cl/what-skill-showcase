# What Skill

A portable alpha toolkit for helping coding agents challenge assumptions, record decisions, and carry project context across sessions.

[Portfolio case study](https://vadim-kravets.vercel.app/) · [Vadim Kravets](https://vadim-kravets.vercel.app/)

## My role

Product direction, problem framing, scope, design decisions, and review. AI coding agents wrote implementation code and tests under my direction. This is an independent portfolio project.

## What to explore

- Project-scoped memory and decision checkpoints
- Skill discovery and recommendation records
- A Python helper, templates, and scenario tests

## Try it locally

```sh
git clone https://github.com/kravitzvadim-cl/what-skill-showcase.git what-skill
cd what-skill
python3 -m unittest discover -s tests -v
```

Read [GUIDE.md](GUIDE.md) for installation. Installing or running it is optional; viewing this repository executes nothing.
